Architecture

Two ways to reach X

TweetPilot supports both browser-based automation via TweetClaw and direct API access — pick the mode that fits your setup.

Chrome Extension Mode

TweetClaw Bridge

Use the TweetClaw Chrome extension as a local WebSocket bridge. TweetPilot connects directly to your logged-in browser session — no API keys needed, no rate limit headaches.

1
Install the TweetClaw Chrome extension from the Web Store
2
Open Twitter/X in Chrome — the extension starts a local WebSocket server on port 20086
3
TweetPilot connects via LocalBridge and can read, post, search, and interact using your browser session
Install TweetClaw from Chrome Web Store
Official X API Mode

X API Direct

Connect with official X API credentials (OAuth 2.0 or API keys) for enterprise-grade reliability. Full access to all X API endpoints with your own developer app credentials.

1
Create an app at developer.twitter.com and obtain your API keys
2
Enter your Consumer Key, Secret, and OAuth tokens in TweetPilot Settings
3
TweetPilot calls X API directly — supports v1.1 and v2 endpoints with automatic credential management

浏览器插件离线安装教程（Zip 压缩包方式）

1

第一步：下载并解压插件压缩包

点击“下载离线 Zip 压缩包”保存 .zip 文件到本地。

在 .zip 文件上点击右键，选择“解压到当前文件夹”或“全部解压缩”，得到解压文件夹。

2

第二步：开启浏览器的“开发者模式”

打开 Chrome 浏览器，点击右上角菜单图标（⋮）→ 选择“扩展程序” → 点击“管理扩展程序”（或在地址栏输入 chrome://extensions 并回车）。

在扩展程序页面右上角，找到并开启“开发者模式”开关。

3

第三步：加载解压后的插件

点击左上角的“加载已解压的扩展程序”按钮。

选择第一步解压出来的文件夹，点击“选择文件夹”完成加载。

4

第四步：固定插件图标

点击 Chrome 右上角“拼图”图标，找到 TweetClaw 旁边的固定大头针图标固定到工具栏。

注：解压文件夹为插件运行必需文件，安装完成后请勿删除或移动该文件夹。
